# --- Model dependencies ------------------------------------------------------
# Pin exact versions: a library upgrade that changes numerics is a REVISION bump.
#
# torch/torchvision versions are a matched pair — torchvision links against a specific
# torch ABI, and a mismatch fails at import, not at install.
#
# NOTE FOR x86_64 DEPLOYS (Hugging Face Spaces): plain `torch` from PyPI pulls ~2.5 GB
# of CUDA runtime on x86_64, which will not fit a free Space. Install from the CPU index
# there: pip install --index-url https://download.pytorch.org/whl/cpu torch torchvision
# On linux/aarch64 (this Docker image on Apple Silicon) the PyPI wheel is already
# CPU-only, so no extra index is needed locally.
